# chcventures.llc

The public website for CHC Ventures LLC.

Three pages of plain static HTML and one hand written stylesheet. No build step, no npm, no framework. Open `index.html` in a browser to preview, or run any static server from this directory.

```
python3 -m http.server 8000
```

Deploy is a push to `main`. GitHub Pages serves it at https://chcventures.llc.

**Before editing anything, read `AGENTS.md`.** It covers the shared block rule, which is the one thing that can silently break this site.
